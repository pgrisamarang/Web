    Verifikasi Data Anggota (NPA)

    Pastikan data keanggotaan Anda terdaftar secara resmi di database Cabang Samarang.

    Prosedur Keanggotaan Baru

    1. Siapkan Berkas

    Siapkan File Foto KTP, email aktif, no. HP, dan pas foto menggunakan Batik PGRI Kusuma Bangsa.

    2. Daftar Secara Mandiri

    Isi data dengan lengkap dan upload file KTP dan pas foto anda. Kemudian ajukan pendaftaran.

    3. Persetujuan Anggota Penerbitan NPA

    Berkas masuk secara daring dan divalidasi oleh admin Cabang Kecamatan. Setelah Admin Cabang menyetujui maka NPA akan otomatis digenerate sistem dan Kartu Tanda Anggota (KTA) akan segera diterbitkan.
